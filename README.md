## DSCI 505: Business Analytics Fundamentals | Fall 2026 | Course Portfolio - Andrew Weyland
## University of South Dakota, Beacom School of Business | Shraddha Gawankar, Ph.D. 
This repository contains data analytics projects, SQL queries, Python scripts, and statistical models developed as part of the MBA in AI for Business Analytics program at the Beacom School of Business, University of South Dakota.

## Tech Stack & Tools
* **Programming Languages:** Python 3.x, SQL, R
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, SciPy, SQLAlchemy
* **Environments:** Jupyter Notebooks, Anaconda, Supabase (PostgreSQL)

## Analytics Framework
Projects in this repository demonstrate the core analytical phases:
1. **Descriptive Analytics:** Data cleaning, aggregations, and visual dashboards.
2. **Predictive Analytics:** Statistical modeling and trend identification.
3. **Prescriptive Analytics:** Translating numerical summaries into business recommendations.
